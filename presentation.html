Problem, requirements, architecture, Free Tier cloud & live demo

01 · Context

One room. Heavy demand. Friction everywhere.

Pain points

  • Booking conflicts under heavy demand
  • No clear view of free slots
  • Manual coordination across associates

Goal

  • Book via natural language
  • Show availability clearly
  • Prevent overlapping bookings
  • Remind before end when next meeting waits
  • Handle extend, cancel, waitlist + insights

Schedule rule: Monday–Friday only

02 · Functional requirements

What the agent must do

1–2 · Availability & booking

“Can I book today from 2–3 PM?”

Check calendar, confirm. Extract date, start, end/duration, purpose.

3 · Conflict detection

If taken: report the conflicting window and suggest nearest free alternatives of equal duration the same day.

4 · 15-min vacate notice

When a booking ends soon and another starts immediately after, email the current occupant to vacate.

5–6 · Extend & cancel

Extend only if free; otherwise name the conflicting associate. Cancel releases the slot and notifies the waitlist.

06 · Booking domain

Rules that survive a wrong LLM answer

Deterministic

  • Overlap on [start, end)
  • Same-day alternatives
  • Extend only if free
  • Cancel → waitlist notify

Persistence

  • Associate · Booking · Waitlist · Room
  • UTC timestamptz
  • CHECK (end > start)
  • Postgres EXCLUDE USING gist

Brevo templates

  • booking.confirmed
  • booking.extended / cancelled
  • booking.vacate_reminder
  • waitlist.slot_available

07 · Key request flows

Four paths that matter in a demo

Availability + book

Extract slot → check_availability → create_booking → Brevo confirmation.

Conflict + alternatives

create_booking fails → suggest_alternatives → list free windows.

Vacate reminder

Job finds end in 15 min with back-to-back next booking → email → set reminder_sent_at.

Extend / cancel

Resolve “my meeting” by associate → extend if free, or cancel and wake waitlist.

12 · Takeaways

What to remember

Product

One shared ODC room, booked in natural language, with hard conflict prevention and operational reminders.

Architecture

Agent proposes; booking service decides. Postgres exclusion constraint is the last line of defense.

Cloud

Free Tier EC2 + Lambda + RDS + EventBridge — fully browsable demo without a local runtime.
